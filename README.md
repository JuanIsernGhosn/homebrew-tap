# JuanIsernGhosn Homebrew tap

Homebrew formulae for my command-line tools.

## Install

```sh
brew install JuanIsernGhosn/tap/autotyper
```

Or tap once and install by name:

```sh
brew tap JuanIsernGhosn/tap
brew install autotyper
```

In a `Brewfile`:

```ruby
tap "JuanIsernGhosn/tap"
brew "autotyper"
```

## Formulae

| Formula | Description |
|---|---|
| [autotyper](https://github.com/JuanIsernGhosn/autotyper) | Type text into any input with human-like rhythm, typos and corrections (macOS) |

## Updating

```sh
brew update
brew upgrade autotyper
```
